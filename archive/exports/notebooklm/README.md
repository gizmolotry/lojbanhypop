# NotebookLM Export Bundle

This archive bucket holds flat text mirrors that are intended for upload into external notebook or summarization tools.

## Current Contents

- `scripts_txt/`: flattened `.txt` mirrors of scripts and run materials that were previously kept at repo root

## Policy

- keep export bundles out of the repo root
- prefer one export target folder per downstream consumer
- preserve historical filenames when possible so old references remain searchable
